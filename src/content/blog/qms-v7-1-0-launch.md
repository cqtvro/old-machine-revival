# 七木数播 v7.1.0 双轨发布：RT 版来了，Pro 版免费升

---

七木数播 v7.1.0 来了。这次是双轨发布：一条是新出的 RT 版，一条是 Pro 版同步升级。两个版本共用一个版本号 7.1.0，区别在内核——RT 版跑真正的 PREEMPT_RT 实时内核，Pro 版跑 LTS 标准内核。先把价格和升级办法说清楚，再说这次修了什么。

## 一、两条线，怎么选

RT 版，599 元终身。跑的是 Linux 6.6.142 PREEMPT_RT 内核，推流线程绑在专核上，跑最高实时优先级。实测数据在 Mac mini 上跑过 5000 次循环：平均 35 微秒，最大 50 微秒。同一台机器跑标准内核，平均 60 微秒，最大 1.7 毫秒。RT 版这版先做单系统，暂不发布双系统 ISO。

Pro 版，299 元终身。跑的是 Linux 6.6.142 LTS 标准内核，界面、功能、曲库这些跟 RT 版是一样的，差别只在底层的实时内核。追求性价比、日常听歌，Pro 版够了。

一句话：想要极致的黑背景和低抖动，选 RT；想要便宜一半、功能一样全，选 Pro。

## 三、这次修了什么

v7.1.0 主要是修了六个平时听歌会碰到的问题：

- **切歌不卡了：** 大曲库里跨专辑切歌，过去偶尔会卡一下，甚至跳回第一首。这版重构了底层调度，切歌直接定位，下一首随心点，不用等。
- **队列不丢了：** 精心挑的几十首歌，一刷新页面或者网络波动，队列突然变成 0 首。这版把队列数据做了持久化，开机、刷新、断网重启，歌单都在。
- **EQ 好用了：** 点“交响爆棚”“醇润人声”这些预设，10 个频段的推子和分贝数跟着一起动，调多少看得见，随时能微调，改完立刻生效。
- **U 盘和开机菜单不乱码了：** U 盘插到 Windows 电脑上，卷标有时候显示乱码；开机引导菜单也没有中文字库。这版都修了：卷标正常显示“七木数播 QMS-RT”，引导菜单中文正常。
- **网络播放更稳：** NAS 上读高码率 DSD 或者 24bit/192kHz 母带，网络一争抢偶尔会抖一下。这版把网络和存储预读拉到 16MB，ALSA 缓冲加到 1000ms，留的余量更大，断流少了。

- **曲库排序正常了：** 过去歌曲按纯文本排，10、11 排在 2 前面，整张专辑顺序全乱；文件夹浏览时子目录排得乱，有时还显示空表头；双碟装的大碟也被拆散了。这版改成按数字大小排曲目编号，按字母和拼音排文件夹，多碟装自动归到一起按顺序连着放。
