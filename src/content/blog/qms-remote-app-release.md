# 老烧友们久等了！七木数播专属手机 APP 正式上线：不接显示器，开机秒连！

---

七木数播出手机 APP 了，Android 版，名字叫 QmsRemote。解决的就是一件事：听歌不用再接显示器、不用再输 IP，躺在沙发上拿手机就能玩。

## 一、不用显示器，也不用输 IP

以前听歌最烦的就是找 IP。数播放进机柜或者音响架，不接显示器不知道 IP 是多少；接了显示器又拖着一根长线，煞风景；手机上输 IP，麻烦还容易输错。

现在不用了。手机连上家里 Wi-Fi，打开 APP，它自己在后台扫局域网，1 秒内找到 QMS 主机并自动连上，一次都不用手动输 IP。

家里有两台数播也不怕，客厅一台、书房一台，APP 自动把在线的都列出来，点一下就换，全屋音乐随便切。

## 二、手机上能干什么

该有的都在手机上，躺沙发上就能操作：

- **六个胆随手换：** 躺在沙发上点一下就换，300B 醇厚人声、KT88 磅礴交响、ECC83 通透高频，歌不停。
- **麦景图双表头：** 手机屏幕上实时跳动左右声道的真实电平，视觉拉满。
- **找歌秒开：** 两万五千多首无损母带，搜一下就出来，选集、加歌单都行。
- **音量：** 硬件音量滑竿，一键静音。
- **网易云：** 每日推荐、红心收藏，都在一屏里。

## 三、怎么装，一分钟上手

下载安装包：[百度网盘](https://pan.baidu.com/s/1j445htW_LeFTTpcvyGT-cQ?pwd=qmsb)，提取码：qmsb；手机连上家里 Wi-Fi；打开 APP，它自动连上数播。完事，开始听。

数播终于可以彻底藏进柜子里了，手机就是遥控器。
