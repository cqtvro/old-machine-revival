把 Windows 电脑变成“文件服务器”，让 Daphile 作为“客户端”去读取音乐。整个过程分为两步：先在 Windows 端开放共享，然后再去 Daphile 端添加路径。

### 第一阶段：在 Windows 电脑上设置共享文件夹

1. **准备文件夹：** 找到想要共享的音乐文件夹（例如命名为 `MyMusic`），右键点击它，选择“属性”。
2. **开启高级共享：** 切换到“共享”选项卡，点击“高级共享”按钮。
3. **设置权限：**
   * 勾选“共享此文件夹”。
   * 点击下方的“权限”按钮。
   * 确保组或用户名列表里有 **Everyone**（如果没有，点击“添加”，输入 Everyone 并确认）。
   * 在 Everyone 的权限列表里，确保勾选了“读取”（如果希望在达菲界面上删除或修改电脑里的文件，可以勾选“完全控制”，但通常“读取”就够了）。一路点击“确定”保存。
4. **关闭密码保护（关键步骤）：** 为了让达菲挂载时更顺利，避免复杂的权限验证，建议在局域网内关闭密码保护。
   * 按下 `Win + S` 搜索并打开“控制面板”。
   * 进入 **网络 and Internet** -> **网络和共享中心** -> 左侧的“更改高级共享设置”。
   * 展开“所有网络”（Windows 11 在底部展开），找到“密码保护的共享”，选择“无密码保护 of 共享”（或关闭选项），保存更改。
5. **获取电脑 IP 地址：** 按下 `Win + R` 输入 `cmd` 回车，在弹出的黑框中输入 `ipconfig`，找到当前连接网络的“IPv4 地址”（例如 `192.168.1.50`），记下它。

---

### 第二阶段：在 Daphile（达菲）端挂载网络驱动器

1. **登录后台：** 确保 Windows 电脑和达菲在同一个路由器下。在浏览器中输入达菲的 IP 地址，进入达菲的 Web 管理界面。
2. **进入存储设置：** 点击左侧菜单底部的 **Settings（设置）**，找到 **Storage（存储）** 版块。
3. **添加网络驱动器：** 在 Storage 版块最下方找到 **Network Drives（网络驱动器）**，点击 **Add new（添加）**。
4. **填写共享信息：**
   * **Share（共享路径）：** 填写 `Windows电脑IP/文件夹名称`。例如：`192.168.6.9/Music`。
   * **Identification（身份验证）：** 因为前面已经关闭了密码保护，这里直接留空即可。（若开启了密码保护，这里就必须按照 `电脑用户名:开机密码` 的格式填写）。
   * **Usage（用途）：** 下拉菜单选择 **Music**。
   * **Type（类型）：** 下拉菜单选择 **smb3**。
5. **保存并重启：** 确认信息无误后，点击页面最下方的 **Save & Restart（保存并重启）**。

---

### 第三阶段：扫描并播放音乐

1. 达菲系统重启完成后，重新刷新浏览器进入后台。
2. 再次进入 **Settings** -> **Storage**，检查刚才添加的网络驱动器，如果后面显示了具体的容量信息，说明挂载成功。
3. 达菲通常会自动开始扫描新加入 of 硬盘音乐。可以让客户点击主界面的 **Audio Players** 或媒体库图标，寻找新增的音乐文件。如果没看到，可以在系统设置里找到 **Rescan（重新扫描）** 按钮，强制刷新一下媒体库。

设置完成后，只要这台 Windows 电脑处于开机且联网的状态，达菲就可以随时读取并播放里面的高品质音乐文件了。
