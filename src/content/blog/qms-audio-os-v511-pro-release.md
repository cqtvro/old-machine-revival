## 🌟 核心升级亮点一览

### 1. 🍏 苹果 Mac mini 原生博通 Wi-Fi 驱动就绪，告别网线束缚
* **硬件级原生编译驱动 (`wl.ko`)**：专为苹果 Mac mini（Late 2012 / Late 2014 等主流型号）所搭载的 Broadcom BCM4360 发烧无线网卡深度定制；
* **双频 2.4G / 5G 高速 Wi-Fi 信号自省**：告别任何复杂的终端命令行，Web 控制台一键扫描周围无线路由，毫秒级快速连接；
* **物理介质原子落盘**：彻底攻克内存系统重启丢失网络配置的历史难题，系统开机自愈连网、智能分配 IP，拔掉有线网线依然稳如泰山。

---

### 2. 📲 音频双向投流中枢：苹果 AirPlay + 局域网发烧雷达

![手机 AirPlay 与局域网高保真无线投流](./images/qms-audio-os-v511-pro/airplay-streaming.jpg)

* **iOS / iPad / Mac AirPlay 无损投流集成**：
  * 内置深度声学优化的 `shairport-sync` 接收核心；
  * iPhone、iPad、Mac 音乐一键投射至七木数播，Apple Music / 播客通过专核 ALSA 直出 DAC 解码器，听感纯净温润；
* **发烧音响 DLNA / UPnP 双向雷达**：
  * **Inbound 手机无线推流**：支持 QQ 音乐、网易云等 QPlay / DLNA 源码投送；
  * **Outbound 母带推流控制器**：QMS 局域网自动雷达嗅探家庭功放与智能电视（如小米电视、发烧流媒体前级），数万首本地母带一键隔空推送。

---

### 3. 💿 SACD ISO 扇区级直解与 DSD64 母带秒播
* **免解压内存扇区直接解算**：无需等待漫长的解包与解压，多轨 / 双声道 SACD ISO 镜像秒点秒播；
* **原生 DSD 直通与高解析 PCM 智能转换**：支持 Native DSD / DoP 直送 USB DAC，针对非 DSD 硬件提供 64-bit 浮点声学滤波转换，保留黑胶般的泛音与细节；
* **专辑 CUE / XML 中文曲目名无损映射**：自动识别曲目内嵌元数据，专辑曲目清单一目了然。

---

### 4. 🛡️ 工业级 A/B 双槽位 (Dual-Slot) 容灾系统与秒级升级
* **航天级系统容灾架构**：内置 A/B 槽位镜像热备份，升级过程只写入备用槽，即使突遇意外断电，系统也能瞬时自愈回退至上一个黄金版本；
* **一键在线固件升级**：支持通过 Web 界面上传 `.qpkg` 升级包，秒级无感热更，全量保留您的曲库索引、名胆 DSP 配置与个人喜好。

---

### 5. 📂 Windows 极速网络拖拽拷歌 (ksmbd 内核套件)
* 内置 Linux 内核级 `ksmbd` 千兆 SMB 共享服务；
* 局域网 Windows 电脑在“网络”中直接发现 `\\QMS` 或输入 `\\数播IP\Music`，免密极速拖拽拷贝 DSD / WAV / FLAC 母带，传输速率轻松跑满千兆网卡。
