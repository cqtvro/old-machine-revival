## 🛠️ 方法一：最简单直观的 PC 客户端中转法（推荐）

这是最适合小白、成功率 100% 的方法。原理是：先在您的电脑上通过客户端拉取配置文件，然后找到本地缓存的 `.yaml` 文件，直接导入进路由器中使用。

### 1. 下载电脑客户端并配置
建议先在当前常用的电脑（Windows / Mac）上下载成熟的开源客户端，如 **Clash Verge**。

*   **下载链接导入**：
    打开 Clash Verge 客户端，进入 **「配置」（Profiles）** 页面。在顶部输入框中粘贴您的专属订阅链接，然后点击旁边的 **Import** 按钮导入。
*   **连接并更新**：
    导入成功后，选中该配置卡片，开启系统代理，确保此时电脑已能正常联通网络。

### 2. 定位并提取本地 YAML 文件
*   在客户端中导入成功的订阅卡片上**点击鼠标右键**，选择 **「在文件夹中显示」（Show in Folder）**。
*   此时系统会自动弹出资源管理器窗口，里面那个以类似格式命名的 `.yaml` 文件（例如 `17865239.yaml`），就是您本地已经下载好的完整配置文件。
*   直接把这个 `.yaml` 文件拷贝出来，上传导入进您的路由器（如 OpenClash 或 Nikki）的配置管理中，启用配置启动服务即可！

> ⚠️ **注意**：使用该中转方法可能导致路由器用户无法自动更新订阅。后续如果订阅节点发生变动，您需要重复上述步骤，重新将新下载的 `.yaml` 文件导入路由器。

## 🛡️ 方法二：OpenWrt SSH 命令行直接拉取（推荐老手）

如果您想在软路由上实现一键自动拉取、更新和无缝运行，可以使用 SSH 命令行在 OpenWrt 终端内直接拉取订阅文件。

本教程推荐使用软路由主流的 **OpenClash** 或 **Nikki** 插件，并统一搭配 **mihomo**（原 Clash.Meta）内核使用。

### ⚙️ 使用环境准备
*   已安装 OpenClash 或 Nikki 插件的 OpenWrt 系统。
*   系统已支持 SSH 或 Shell 终端访问（推荐使用 MobaXterm 或 Putty 连接路由器）。

### 1. 安装插件
在 OpenWrt 后台网页端的 **「系统 -> 软件包」** 中，搜索并安装以下任意一个插件：
*   **OpenClash**
*   **Nikki**

### 2. 下载 mihomo 内核
推荐从官方 Release 页面下载对应您 OpenWrt 软路由 CPU 架构的 mihomo 二进制内核文件。

*   **官方下载地址**：[https://github.com/MetaCubeX/mihomo/releases](https://github.com/MetaCubeX/mihomo/releases)
*   **选择架构**：请根据您的 OpenWrt 硬件架构选择对应版本（例如电脑软路由选 `amd64`，普通路由器硬件选 `arm64` 或 `mips`）。
*   **配置内核**：下载完成后，将内核文件放入对应插件的内核目录中，并执行 `chmod +x` 命令赋予其执行权限。

### 3. 获取订阅配置文件（Shell 命令）
使用 SSH 工具连接登录您的 OpenWrt 路由器后台，然后在终端中执行以下命令（通过模拟 `mihomo` 客户端的 User-Agent 来拉取）：

```bash
curl -A mihomo '您的订阅链接' -o mihomo.yaml
```

> ⚠️ **操作提示**：请把命令中的 `'您的订阅链接'` 替换为您的真实订阅地址。执行该命令后，系统将在当前目录下生成完整的 `mihomo.yaml` 配置文件。

### 4. 导入配置并启动
*   登录 OpenWrt 网页后台，进入插件管理页面。
*   在配置文件管理中，上传或导入刚刚生成的 `mihomo.yaml`。
*   应用配置，启用服务并启动插件，即可正常开始网络分流体验！

## 🙋 常见问题排查

*   **Q：配置启动后连接异常，打不开网页？**
    *   **A**：请先检查并更新您的订阅源；
    *   确保在插件的内核选择中，已经选中并开启了 **`mihomo`** 内核，而不是旧版且已停止维护的 `clash` 内核。
*   **Q：节点失效后怎么更新？**
    *   **A**：如果使用方法二，直接在终端里重新运行 `curl` 命令拉取即可替换更新。
